# jdtls-shaded-bundle

Shaded bundle of the [Eclipse JDT Language Server](https://github.com/eclipse-jdtls/eclipse.jdt.ls) (jdtls).

## Status

Skeleton repository. Build system and packaging to be added.

## Goal

Produce a single self-contained (shaded) artifact bundling jdtls and its
runtime dependencies for easy distribution and embedding.
